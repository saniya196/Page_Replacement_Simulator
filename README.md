# Page-Replacement Simulator

Visual simulator for OS page replacement algorithms: **FIFO, LRU, Optimal**.

Tabs: Simulation, Compare All, Algorithms, Code in C.

## Run locally
Open `index.html` in a browser. No build step.

## Deploy on GitHub Pages
1. Create a new repo (for example `Page_Replacement_Simulator`).
2. Upload `index.html`, `style.css`, `script.js` (or push with git).
3. Repo Settings -> Pages -> Source: Deploy from a branch -> `main` / `(root)` -> Save.
4. Your site: `https://<username>.github.io/Page_Replacement_Simulator/`
